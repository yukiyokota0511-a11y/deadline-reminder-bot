# 締切リマインダーBot

大学の課題・レポートの締切を毎朝チェックし、締切が近いものをDiscordに自動通知するBotです。

## 背景・作った理由

大学の課題やレポートは複数の授業で並行して発生し、大学ポータルを毎回自分で確認しないと締切に気づけません。
手帳やメモで管理していても更新を忘れがちで、「気づいたら明日が締切だった」ということが度々ありました。
この課題を解決するため、締切が近づいたら自動でDiscordに通知するBotを開発しました。

## 主な機能

- JSONファイルで締切データを一元管理
- 締切の3日前から毎日、Discordに自動通知
- GitHub Actionsにより、パソコンを起動していなくても毎朝自動実行

## 使用技術

- Python 3.14
- `datetime`（締切までの日数計算）
- `requests`（Discord Webhookへの通知送信）
- `python-dotenv`（環境変数の管理）
- GitHub Actions（定期実行・CI/CD）
- Discord Webhook

## 仕組み

1. GitHub Actionsが毎朝8:00（JST）にスクリプトを自動実行
2. `deadline_checker.py`が`deadlines.json`を読み込み、3日以内の締切を判定
3. 該当する課題があれば`notifier.py`がDiscord Webhookへ通知を送信
4. 該当がなければ何もせず終了（通知のノイズを防止）

## 工夫した点・学んだこと

Discordを使うのがほとんど初めてだったので、通知が届かなかったときに何が原因なのか全然わからず、一番手こずったところでした。エラーは出ていなかったので「たぶん送信はできているはず」と思っていたのですが、実は保存し忘れたまま実行していたのが原因で、保存してから実行し直したら無事に解決しました。この経験から、エラーが出ていないからといって正しく動いているとは限らないこと、迷ったらまず出力（レスポンスの中身など）を確認してみることの大切さを学びました。

もう一つ印象に残っているのは、Discord WebhookのURLを`.env`や`.gitignore`、GitHub Secretsで管理したことです。最初は正直「そのままコードに書いた方が早いのに」と思っていましたが、GitHubはみんなが見られる場所なので、自分の大事な情報をそのまま載せてはいけないということを実感しました。一見遠回りに見える作業ほど、実は大事な意味を持っているのだと気づけたのは、今回一番の学びだったと思います。
